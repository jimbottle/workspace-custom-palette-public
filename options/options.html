Custom Color Palette

These colors appear as a “Brand” row inside the native color pickers in Google Docs, Sheets, and Slides. Edits apply the next time you open a picker, with no reload needed.

Your organization provides a default palette. You can change these colors for yourself.

Import / export

One color per line, name then hex, like Brand Blue #1A73E8. Paste a list to import, or copy the current palette to share. With Multiple palettes on, importing makes a new palette that you name and switches to it, so nothing you already have is replaced.

Keep more than one palette and switch between them.
Publishing brand colors to a Workspace domain? This builds the settings to paste into the Google Admin console. You need to be an administrator.

Interested but not sure where to start? Follow the step by step setup guide, or email dev@raylytics.io. I'm happy to help set up an organization palette at no cost.
