# Store asset capture guide

The images the Chrome Web Store listing needs, with specs and a short shot list.
Listing copy lives in `STORE_LISTING.md`.

## Required dimensions

| Asset | Dimensions | Required? | Notes |
|---|---|---|---|
| Icon 128x128 | 128 x 128 | Yes | `icons/icon128.png`, generated by `npm run icons` |
| Screenshots | 1280 x 800 *or* 640 x 400 | At least 1, 3-5 recommended | 24-bit PNG, no alpha |
| Small promo tile | 440 x 280 | Required for any promotion | PNG/JPG, no alpha |
| Marquee promo tile | 1400 x 560 | Optional | Unlocks featured placement |

CWS rejects transparency on promo tiles. Every image here is rendered as 24-bit
RGB, so there is nothing to flatten by hand.

## Output paths

```
store-assets/
  templates/                  HTML for every designed image; edit these, never the PNGs
    art.css                   shared look (colors, type, picker mock, shot layout)
    marquee.html  small.html  promo tiles
    shot-apply.html  shot-editor.html  shot-popup.html
    shot-managed.html  shot-builder.html
  promo/
    small-440x280.png
    marquee-1400x560.png
  screenshots/
    _raw/                     raw captures (any size), framed by the templates
      raw-sheets-apply.png    (by hand, see 01)
      raw-options-editor.png
      raw-popup-editor.png
      raw-managed-palette.png
      raw-policy-builder.png
    01-brand-row-sheets.png   (1280x800) the hero shot
    02-options-editor.png
    03-popup-editor.png
    04-managed-palette.png
    05-policy-builder.png
```

Every image carries the "Custom Color Palette" mark (the name settled on
2026-08-26; the hand-made art before 2026-10-08 still said "Brand Palette").
Headlines and body lines are shipped user copy: no em-dashes.

## Capturing

```
npm run shots
```

Two steps:

1. `dev/capture-shots.mjs` (Playwright + the Chromium already under `monitor/`)
   renders the REAL `options.html`, `popup.html` and `policy-builder.html` with
   a `chrome.*` stub, so each page mounts the packaged default palette exactly
   as shipped, and writes the raws to `_raw/`. The `managed-palette` target
   passes a locked managed policy, so Settings renders as a force-installed
   copy does. Dark theme by default; `--light` for the light variant.
2. `dev/render-store-art.mjs` renders every file in `templates/` at its exact
   store size and flattens it to 24-bit RGB.

No extension or Google login is needed: re-run it after any UI or palette
change. (The raws are renders of the shipped page code, not grabs from an
installed extension, but they are pixel-faithful to those pages.) The templates
load Inter from Google Fonts; offline, the renderer warns and falls back to the
system font.

### 01 (Sheets hero): raw by hand

The hero needs the extension actually injecting into a signed-in Google Sheets
tab, which automation can't reach. Capture it manually, drop it in
`_raw/raw-sheets-apply.png`, then run `npm run shots` (or just
`node dev/render-store-art.mjs`).

1. Clean Chrome profile (or guest), no other extensions or bookmarks bar
   (`Cmd+Shift+B`), 100% zoom; load the extension and confirm the Brand row shows.
2. Open a Sheet, fill a few cells with brand colors, open the fill-color picker so
   the Brand row is visible, and box it. Save as `_raw/raw-sheets-apply.png`.

## Shot list

### 01 — Brand row in a Sheet (hero, apply)
The whole pitch in one image: the fill-color picker open, the Brand row boxed,
cells already filled. **"One click, in Google's own picker"**

### 02 — Settings palette editor (set)
The seven named colors with chip, name, hex and copy, eyedropper, reorder and
remove, plus Add color / Reset / Save. **"Set your brand colors once"**

### 03 — Toolbar popup editor (set)
The popup's inline editor with Undo/Redo and the footer links.
**"Edit them from the toolbar"**

### 04 — Organization palette, as staff see it (admin)
Settings on a force-installed copy: the org colors, locked, with New palette
for colors of one's own. **"Roll one palette out to your organization"**, body
names the Google Admin console force-install.

### 05 — Policy builder (admin)
What to publish, the lock, the colors, and the generated JSON for "Policy for
extensions". **"Admins pick the colors, it writes the policy"**

## Promo tiles

`templates/small.html` (440x280) and `templates/marquee.html` (1400x560): the
mark, the headline ("Brand colors, one click."), a line or chip that names the
organization case, and a mock Google picker with the Brand row boxed.

## After capture

1. Look at every image; keep each file < 1 MB.
2. Tick the asset boxes in `STORE_LISTING.md`, then upload via the CWS
   Developer Dashboard → Store listing tab.
